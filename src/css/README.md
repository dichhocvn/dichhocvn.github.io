# src/css/
- Tổng hợp qua `src/styles.css` (import theo thứ tự: base → chat → forms → grid → modals).
- `base.css`: variables, reset, shell layout (toàn page padding 2px; cột trái desktop cao 100vh; khi chatbot ẩn thì `#formArea` chiếm full chiều cao còn lại).
- `chat.css`: UI chat panel + nút toggle chatbot cố định dưới cùng cột trái desktop; có trạng thái disabled màu xám khi chưa hỗ trợ bật lại chatbot.
- `forms.css`: form input, tab, grid wrapper, search chips; layout mobile: nút Lập lá số căn giữa, ẩn dòng quy đổi Âm lịch trên tab DL, form tìm lá số/cấu hình gọn (grid 2 cột cfg trên mobile); mobile chọn ngày/tháng/giờ bằng select (`form-mobile-select` / `gio-mobile-row`), input gốc `form-desktop-number-input` ẩn trực quan; tách class cho search nav để style mobile/desktop riêng + lề dưới lá số (grid) 2px; khi chatbot ẩn trên desktop thì tab panel active (`form/search/cfg`) giãn full-height; tab bar sticky ở đầu vùng form desktop khi cuộn; có state khóa `cfgPanel` khi dùng template `lyso.vn`; `laso-wrap` có biến reserve top (`--laso-overflow-top-reserve`, mặc định `50px`) để dồn phần tăng chiều cao lá số lên trên; nav kết quả có thêm nút sao riêng `#listLasoStar` ở cả web và mobile .
- `grid.css`: cung/sao/grid/highlight/pills; ô giữa `.center-bg` chỉ hiện SVG khi `#lasoWrap.laso-center-decor-yinyang`; ảnh nền `.center::before` + `--laso-center-bg` khi `laso-center-wallpaper-on` (URL ảnh gán từ JS, thường GitHub raw; khung ảnh `8.6cm x 11.4cm` = `2x2` ô, opacity `0.5`); mode `laso-center-width-priority` dùng `background-size: 100% auto` để ưu tiên ngang đủ 2 ô và cắt phần dọc tràn; mode còn lại giữ `cover`; bảng info center đã bỏ dải phân cách ngang; tách class cho cụm điều hướng xem hạn để style mobile/desktop riêng (mobile giữ top padding `3px` ở `hanNavBar`); tăng lớp hiển thị khu chính tinh và chỉnh header để vị trí 1/3 có width bằng nhau, vị trí 2 luôn centered và không bị đại vận che; sao hung (vị trí 6) được căn phải theo cột hung (`col-hung` align-items:flex-end), giữ một dòng và canh mép phải ổn định, tránh đè viền; cát tinh vẫn cho phép overflow.
- `modals.css`: prompt modal + rule modal.
