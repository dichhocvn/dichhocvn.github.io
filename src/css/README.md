# src/css/
- `base.css`: variables, reset, shell layout (toàn page padding 2px; cột trái desktop cao 100vh và có scroll).
- `chat.css`: UI chat panel + nút Ẩn/Hiện chatbot desktop + trạng thái xám khi tắt xem hạn.
- `forms.css`: form input, tab, grid wrapper, search chips; tách class cho search nav để style mobile/desktop riêng + lề dưới lá số (grid) 2px.
- `grid.css`: cung/sao/grid/highlight/pills; tách class cho cụm điều hướng xem hạn để style mobile/desktop riêng.
- `modals.css`: prompt modal + rule modal.
