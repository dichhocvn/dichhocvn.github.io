# src/js/utils/
- `diachi.js`: Địa chi — `NAMES`, `KEYS`, `MONTH_KEYS`; `keyToIdx`, `nameToIdx`, `splitPairToIdx`; `toIdx` (tên có dấu hoặc key ASCII); **`getNext`** / **`getNexts`** (bước thuận trên vòng 12 chi, luôn trả về chuỗi trong `NAMES`; tương ứng `DiaChiManager` Java). Global: `TUVI_DIACHI_UTIL`.
- `thiencan.js`: Thiên can — `NAMES`, `KEYS`, `keyToIdx`, `nameToIdx`. Global: `TUVI_THIENCAN_UTIL`.
- `cungchuc.js`: Cung chức — `ORDER` (≈ `TEN_CUNG`), `indexOf`. Global: `TUVI_CUNGCHUC_UTIL`.
