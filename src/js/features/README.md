# src/js/features/
Các file độc lập theo tính năng UI.

- `lunar-calendar.js`: đổi Dương↔Âm; `validateSolarDateInput` / `validateAmLichDateInput` / `syncDlInputsFromAmLich` (DL ↔ ô âm cho template lyso).
- `lap-so-dialog.js`: `validateLapSoDateInputs` + overlay `#lapSoValidationOverlay` khi ngày không hợp lệ trước khi Lập lá số (mobile + desktop).
- `gio-controls.js`, `han-controls.js`: điều khiển giờ/năm xem hạn; chỉ khóa điều hướng năm khi tắt Xem hạn, điều hướng giờ vẫn luôn dùng được; nếu đang template `lyso.vn` thì đổi năm xem hạn sẽ refresh ảnh API theo năm mới; `onNamXemChange` giữ `#luuModeBar` ẩn khi template lyso (ảnh API không theo chế độ an sao lưu).
- `chatbot.js`: panel chat (desktop đang ẩn mặc định; nút dưới cùng cột trái hiển thị trạng thái disabled "sắp hỗ trợ", chưa cho bật lại chatbot).
- `prompt-export.js`: modal xuất prompt/json.
- `theme-config.js`: template + css variables; thêm template `lyso.vn` để khóa chỉnh màu thủ công, render ảnh API ngay trong vùng lá số, ẩn legend/nút prompt/`#luuModeBar` và build URL API theo dữ liệu form + năm xem hạn; chọn nền ô giữa (`#lasoBgSelect`): Không nền (`laso-center-plain`: không ảnh/SVG), Âm Dương vector (`laso-center-decor-yinyang` + `laso-center-width-priority`), hoặc ảnh qua `LASO_BG_RAW_BASE` + `LASO_BG_FILES` (GitHub raw; label không đuôi); ảnh → `--laso-center-bg` (`lasoBgAbsoluteUrlForCss`) + `laso-center-wallpaper-on`, riêng các ảnh trong `LASO_BG_WIDTH_PRIORITY` sẽ thêm `laso-center-width-priority` để ưu tiên bám ngang 2 ô; giá trị localStorage cũ không còn trong danh sách bị bỏ; sau đổi template khỏi lyso gọi lại `applyLasoBackgroundChoice`; không hiệu lực khi khóa lyso API).
- `layout-*.js`: responsive/resize/scale; `layout-scale.js` cố định khung hiển thị theo chiều cao chuẩn 4 hàng, rồi dùng `translateY(...)` để dồn phần lá số tăng thêm (do nhiều sao) lên trên theo reserve top (đọc từ `--laso-overflow-top-reserve`, hiện đặt 50px trong `forms.css`). Các mũi tên lá số dùng id `#btnLasoPrev/#btnLasoNext` và bind event trong `search-laso.js`; mũi tên năm hạn/giờ sinh dùng `#btnNamXemPrev/#btnNamXemNext` và `#btnGioXemPrev/#btnGioXemNext` bind trong `han-controls.js`/`gio-controls.js` (không dùng class để xử lý click).
- `form-mobile-pickers.js`: trên `body[data-layout="mobile"]` hiện `<select>` cho ngày/tháng (ÂL + DL) và cặp giờ–phút; ẩn input số/giờ bằng `form-desktop-number-input` + `form-mobile-select`; đồng bộ với `#ngay`…`#gio` và gọi `syncMobilePickersFromInputs` sau khi code khác gán giá trị.
- `search-laso.js`: tab tìm kiếm lá số — ngày bắt đầu DL nhập Ngày/Tháng/Năm riêng + «Số ngày» (quét N ngày dương lịch liên tiếp từ ngày đầu); tự quét 12 giờ sinh, nav có vị trí `a/b`, rời tab Search rồi sửa dữ liệu sẽ tự xóa kết quả cũ; lỗi validate mở dialog trên desktop (hiển thị message dạng plain, không đánh số); mobile khi quét xong hiển thị dialog tóm tắt kết quả (thay vì in text status); mỗi item kết quả hiển thị số cát tinh/hung tinh mục tiêu (hung có cả Hóa Kỵ, so sánh trực tiếp theo `name` có dấu + lowercase, chỉ bỏ trạng thái miếu/vượng/đắc/hãm; regex marker M/V/B/H chỉ áp dụng khi là token rời để không ăn nhầm chữ đầu tên sao), chủ tinh kèm sức mạnh `(M/V/B/H)`, badge Tuần/Triệt nền đen và phạt điểm cát khí -20 khi có Tuần hoặc Triệt tại Mệnh, cờ Cô/Quả (chỉ hiển thị khi có), giờ sinh dạng khoảng (`1h-3h`); danh sách sort giảm dần theo điểm, nếu bằng điểm thì ưu tiên hiệu số (cát tinh-hung tinh) lớn hơn rồi mới đến ngày gần mốc bắt đầu hơn; mỗi item có nút sao để đánh dấu lưu, `#listLaso` luôn mở danh sách đầy đủ, `#listLasoStar` luôn mở danh sách item đã sao (web + mobile); có thể bật/tắt sao ngay trong overlay mà không làm đóng hoặc mất danh sách; danh sách sao render trong overlay riêng nên không làm đổi/scroll `searchResultList` hiện tại; toggle sao trong list chính chỉ cập nhật item tại chỗ, không chuyển sang star-view; có nút chọn tất cả/bỏ chọn tất cả cho tổ hợp chính tinh Mệnh; đã bỏ các filter phụ Cát tinh/Hung tinh/Tuần-Triệt khỏi UI tìm kiếm; khi template là `lyso.vn`, tìm kiếm vẫn dùng thuật toán local nhưng lúc chọn từng kết quả sẽ gọi API ảnh để hiển thị.
