# src/js/features/
Các file độc lập theo tính năng UI.

- `lunar-calendar.js`: đổi Dương↔Âm.
- `gio-controls.js`, `han-controls.js`: điều khiển giờ/năm xem hạn; chỉ khóa điều hướng năm khi tắt Xem hạn, điều hướng giờ vẫn luôn dùng được; nếu đang template `lyso.vn` thì đổi năm xem hạn sẽ refresh ảnh API theo năm mới; `onNamXemChange` giữ `#luuModeBar` ẩn khi template lyso (ảnh API không theo chế độ an sao lưu).
- `chatbot.js`: panel chat (desktop đang ẩn mặc định; nút dưới cùng cột trái hiển thị trạng thái disabled "sắp hỗ trợ", chưa cho bật lại chatbot).
- `prompt-export.js`: modal xuất prompt/json.
- `theme-config.js`: template + css variables; thêm template `lyso.vn` để khóa chỉnh màu thủ công, render ảnh API ngay trong vùng lá số, ẩn legend/nút prompt/`#luuModeBar` và build URL API theo dữ liệu form + năm xem hạn; chọn nền ô giữa (`#lasoBgSelect`): Không nền (không ảnh, không SVG), Âm Dương vector (`laso-center-decor-yinyang`), hoặc ảnh từ `resources/background-laso/` (`LASO_BG_FILES`, label không đuôi); ảnh → `--laso-center-bg` (URL tuyệt đối qua `new URL` để tránh resolve sai khi biến CSS dùng trong `grid.css`) + `laso-center-wallpaper-on`; giá trị localStorage cũ không còn trong danh sách bị bỏ; sau đổi template khỏi lyso gọi lại `applyLasoBackgroundChoice`; không hiệu lực khi khóa lyso API).
- `layout-*.js`: responsive/resize/scale.
- `search-laso.js`: tab tìm kiếm lá số — ngày bắt đầu DL nhập Ngày/Tháng/Năm riêng + «Số ngày» (quét N ngày dương lịch liên tiếp từ ngày đầu); tự quét 12 giờ sinh, nav có vị trí `a/b`, rời tab Search rồi sửa dữ liệu sẽ tự xóa kết quả cũ; lỗi validate mở dialog trên desktop (hiển thị message dạng plain, không đánh số); mỗi item kết quả hiển thị số cát tinh/hung tinh mục tiêu (hung có cả Hóa Kỵ, so sánh trực tiếp theo `name` có dấu + lowercase, chỉ bỏ trạng thái miếu/vượng/đắc/hãm; regex marker M/V/B/H chỉ áp dụng khi là token rời để không ăn nhầm chữ đầu tên sao), chủ tinh kèm sức mạnh `(M/V/B/H)`, badge Tuần/Triệt nền đen và phạt điểm cát khí -20 khi có Tuần hoặc Triệt tại Mệnh, cờ Cô/Quả (chỉ hiển thị khi có), giờ sinh dạng khoảng (`1h-3h`); danh sách sort giảm dần theo điểm rồi đến ngày gần mốc bắt đầu hơn; có nút chọn tất cả/bỏ chọn tất cả cho tổ hợp chính tinh Mệnh; đã bỏ các filter phụ Cát tinh/Hung tinh/Tuần-Triệt khỏi UI tìm kiếm; khi template là `lyso.vn`, tìm kiếm vẫn dùng thuật toán local nhưng lúc chọn từng kết quả sẽ gọi API ảnh để hiển thị.
